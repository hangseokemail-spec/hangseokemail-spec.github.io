# 목표·노후 개편 초안 (Claude 작성 → Opus 검토, GPT 디자인, Fable 컨펌)

## 사용자 요청(원문 요지)
- "오늘 돈 / 미래 돈" 스위치가 복잡하다. **저울**로: 왼쪽 접시 오늘 돈, 오른쪽 접시 그해 돈, 저울 가운데(받침)에 **기간·물가상승률**. 양쪽이 같은 가치임을 한눈에.
- 가로형 카드 ① **돈의 가치 저울(목표 정하기)**
- 가로형 카드 ② **실행 목표 만들기** — 궁금한 것 4가지:
  1. 지금 돈을 몇 % 수익률로 넣으면 **얼마 만에** 달성? (기간)
  2. 이 기간, 이 수익률이면 **매달 얼마** 넣어야? (월 적립액)
  3. 예금처럼 한 번에 넣는다면 **처음에 얼마** 있어야? (초기 목돈)
  4. 이 돈으로 이 기간에 달성하려면 **몇 % 수익률**이어야? (필요 수익률)

## 화면 구조(초안)
목표·노후 탭 맨 위에 카드 두 장을 가로로(넓은 화면 1280px+: 두 장 나란히 5:7, 휴대폰: 위아래).
그 아래에 지금의 '자세한 계획'(구간별 수익률·목돈 나이 띠·연금·실제 기록)을 그대로 둔다.

### ① 돈의 가치 저울
```
 ┌───────────────────────── 돈의 가치 저울 ─────────────────────────┐
 │   [오늘 돈]                                  [2046년 통장 숫자]   │
 │   1억원                ⚖                      1억 6,386만원        │
 │  ─────────────────────▲─────────────────────                      │
 │                 [20]년 · 물가 연 [2.5]%                            │
 │  "오늘 1억원과 2046년의 1억 6,386만원은 같은 가치예요."            │
 │  [이 금액을 목표로 ▶]                                              │
 └────────────────────────────────────────────────────────────────────┘
```
- 어느 접시 금액을 고쳐도 다른 접시가 바뀐다: 그해 = 오늘 × (1+물가)^기간, 오늘 = 그해 ÷ (1+물가)^기간.
- 기간·물가를 고치면 '마지막으로 손댄 접시'를 고정하고 반대쪽이 바뀐다.
- 입력 중에는 저울이 고친 쪽으로 살짝 기울었다가(0.25초) 수평으로 돌아온다 → "값이 맞춰졌다"는 느낌. 동작 줄이기 설정이면 애니메이션 없음.
- '이 금액을 목표로'를 누르면 ②의 목표 금액(그해 통장 숫자)과 기간이 채워진다.
- 기존 '{year}년 통장 숫자 / 오늘 돈으로' 스위치, 목표 기준(nominal/today) 스위치, 국밥 막대(valueBridge)는 없앤다. 결과 숫자는 모두 '그해 통장 숫자'로 쓰고, 필요한 곳에만 "(오늘 돈 X)"를 작게 덧붙인다.

### ② 실행 목표 만들기
```
 ┌──────────────────────── 실행 목표 만들기 ─────────────────────────┐
 │ 무엇이 궁금해요?  (●기간) (○매달 넣을 돈) (○처음 목돈) (○수익률) │
 │ 목표 [1억 6,386만원] (2046년 통장 숫자)                            │
 │ 지금 목돈 [3,000만원]  매달 [50만원]  연수익률 [6]%  기간 [ ? ]    │
 │ ───────────────────────────────────────────────────────────────── │
 │  답: 12년 (2038년 11월)                                       │
 │  [넣은 돈 ███████ | 불어난 돈 ████]  (막대)                         │
 │  다른 길: 매달 70만원이면 10년 / 수익률 8%면 11년 7개월            │
 │  [이 값으로 아래 계획에 반영] [연 6% 수익률 내는 투자 규칙 찾기 →]   │
 └────────────────────────────────────────────────────────────────────┘
```
- 고른 항목은 입력칸 대신 '?' 결과칸으로 바뀐다. 나머지는 입력칸.
- 계산 규칙(지금 엔진과 같게): 월 수익률 i = (1+r)^(1/12) − 1, 적립은 월말, 기간은 개월 단위.
  - FV(n) = P0·(1+i)^n + C·((1+i)^n − 1)/i (i=0이면 P0 + C·n)
  - 기간: FV(n) ≥ 목표가 되는 가장 작은 n(최대 100년). 없으면 '닿지 못함'.
  - 매달: C = (T − P0·(1+i)^n)·i / ((1+i)^n − 1). 0 이하면 '지금 목돈만으로 충분'.
  - 처음 목돈: P0 = (T − C·((1+i)^n−1)/i) / (1+i)^n. 0 이하면 '매달 적립만으로 충분'.
  - 수익률: 이분법(−50% ~ 100%), 연 1bp 정확도. 연 15% 초과면 '현실적으로 어려움' 경고, 30% 초과면 '수익률만으로는 어려움'.
- 못 닿을 때는 꼭 대안을 같이: (기간) 매달 얼마면 / 수익률 몇 %면 / 목돈 얼마 더면. (수익률) 기간 몇 년이면 / 매달 얼마면.
- 계산 결과 아래에 원금(넣은 돈)과 수익(불어난 돈) 비율 막대.
- '이 값으로 아래 계획에 반영': 목표 모드 계획의 goalAmount·goalYears·initial·monthly·accSegs(단일 수익률)를 채운다.
- 노후 자금 모드에서는 ②의 목표를 '은퇴 때 필요 자금(그해 숫자)'·기간을 '은퇴까지 남은 해'로 미리 채운다.

## 저장
- 계획마다 `calc: {ask:'years'|'monthly'|'initial'|'rate', target, initial, monthly, rate, years}`와 `scale: {today, years, inflation, last:'today'|'then'}`를 둔다(계정 vault로 저장되는 ss.plans 안).
- 예전 계획은 처음 열 때 기존 값(goalAmount, goalYears, initial, monthly, 첫 구간 수익률, inflation)으로 채운다.
