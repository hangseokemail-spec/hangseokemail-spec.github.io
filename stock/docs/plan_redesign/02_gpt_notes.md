# Seok’s Stock · 목표·노후 카드 제안

## 화면과 그래픽

- **돈의 가치 저울**은 오늘 돈을 왼쪽, 그해 통장 숫자를 오른쪽에 놓는다. 서로 다른 금액 아래로 수평 가로대가 이어지고, 가운데 받침에 기간과 연 물가상승률을 둔다. 하단의 ‘같은 가치’ 문구가 저울의 뜻을 한 번 더 전한다.
- **실행 목표 만들기**는 ‘무엇이 궁금해요?’에서 한 항목을 고르게 한다. 선택 버튼에 배경과 테두리를 적용하고, 해당 입력 자리에는 같은 높이의 ‘?’를 표시한다. 답은 예상 도달 시점이나 만기 금액과 함께 바로 아래에 둔다.
- 막대는 넣은 돈과 불어난 돈의 금액을 각각 적고 비중을 길이로 보여 준다. 상승분은 빨강, 손실분은 파랑을 쓴다. 손실일 때는 넣은 돈 전체를 기준으로 남은 부분과 줄어든 부분을 나누고 ‘줄어든 돈 −…’으로 표시한다.
- 필요 수익률이 높으면 수익률과 경고를 함께 보여 주고 연 6%를 가정한 기간·적립액을 대안으로 제시한다. 대안 칩을 누르면 그 조건으로 다시 계산한다.
- 1280px 시안은 두 카드를 5:7로 배치한다. 390px 시안은 저울과 실행 목표를 차례로 쌓고, 질문 버튼과 조건 입력을 2열로 줄인다. 실행 버튼은 세로로 늘리고, 대안 칩은 넘치면 줄바꿈한다. 시안 페이지 공간이 부족하면 가로로 스크롤하며, 720px 이하에서는 휴대폰 틀을 먼저 배치한다.

## 계산과 표시

| 시안 | 결과 |
| --- | --- |
| 저울 | 1억원 × 1.025²⁰ = 163,861,644.03원 → 만원 단위 표시 1억 6,386만원 |
| 기간 | 목표 163,860,000원, 목돈 3천만원, 월 50만원, 연 6%. 143개월에 163,046,163원, 144개월에 164,339,798원으로 처음 도달. 시안 기준일 2026년 11월에서 2038년 11월 도달 |
| 기간 막대 | 144개월간 넣은 돈 1억 200만원, 불어난 돈 약 6,234만원 |
| 수익률 | 같은 목돈과 적립으로 10년 안에 달성하려면 연 8.82%. 휴대폰 틀 위의 ‘10년 수익률 예시’로 확인 |
| 대안 | 3년 목표에는 연 60.81%가 필요. 연 6%로 3년 동안 모으면 약 5,535만원. 연 6%를 기준으로 기간을 12년 0개월로 늘리거나, 3년을 유지하며 월 적립액을 327만원으로 올리는 경로를 표시 |

월 수익률은 `i = (1 + 연수익률)^(1/12) − 1`, 적립은 월말 기준이다. 기간은 월 단위로 처음 목표에 닿는 달을 찾고, 필요 수익률은 연 −50%~100% 구간에서 이분법으로 찾는다. 금액 말뜻은 만원 부분이 정확히 천의 배수일 때만 ‘천’으로 줄인다. 예를 들어 2,000만원은 ‘2천만원’, 2,500만원은 ‘2,500만원’이다. 금액 입력 바로 아래에 `--text-3`으로 붙인다.

## 상호작용

- **입력과 전달** — 입력을 마치면 반대쪽 접시를 다시 계산한다. 기간이나 물가를 고치면 마지막에 직접 고친 접시를 기준으로 삼는다. ‘이 금액을 목표로’는 그해 통장 숫자와 기간을 채운다. 기간을 묻는 상태에서는 전달된 기간을 볼 수 있게 필요 수익률로 전환한다.
- **움직임** — 가로대는 (180, 79)에서 고친 쪽으로 3.5° 기울고 250ms 안에 수평으로 돌아온다. 각 접시는 줄째 회전한 가로대 양 끝으로 평행 이동한다. ‘저울 움직여 보기’는 양쪽을 번갈아 시연한다. 동작 줄이기 환경에서는 움직임 없이 금액을 갱신한다. SVG의 점선 상자는 받침 위 HTML 입력의 위치를 나타내며 인라인 시안에서는 HTML 컨트롤로 덮는다.
- **포커스와 눌림** — 키보드 포커스는 2px `--focus-ring`과 2px 여백으로 표시한다. 질문 선택에는 `aria-pressed`를 붙인다. 버튼을 누르는 동안 배경과 안쪽 테두리를 바꾼다. 목표 전달 뒤 목표 입력으로, 대안 적용 뒤 기간 선택으로 포커스를 옮긴다. 조작 영역은 최소 44px다.
- **오류와 안내** — 잘못된 입력에 `aria-invalid`를 붙이고 테두리와 짧은 안내를 표시한다. 결과와 안내는 라이브 영역으로 전달한다. 계산이 어렵거나 입력이 잘못되면 계획 반영과 투자 규칙 버튼을 비활성화한다. 낮은 수익률로 다시 계산할 수 있는 경우 대안 칩을 함께 둔다.
- **앱 연결 제안** — 시안의 계획 반영은 바로 아래 요약에 표시된다. 앱에서는 목표 모드의 `goalAmount`, `goalYears`, `initial`, `monthly`, `accSegs`에 연결한다. 투자 규칙 버튼은 시안에서 연결 안내를 표시한다. 노후 모드에 적용할 때는 은퇴 시점 필요 자금과 은퇴까지 남은 기간을 초기값으로 사용한다.
