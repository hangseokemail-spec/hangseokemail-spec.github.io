# 석스 가판대

https://hangseokemail-spec.github.io/ — 석스가 만든 것들을 한 화면에 모아 보는 페이지입니다.

- `index.html` 화면과 디자인
- `hub.js` 각 프로그램의 발행 기록을 읽어 최신 호 표지를 그리는 코드
- `projects.json` **프로그램 목록. 새로 만든 것은 여기에만 추가하면 됩니다.**
- `home.js` 각 프로그램 화면에 떠 있는 '가판대' 단추
- `summaries.json` 호마다 직접 쓴 핵심 한 문장
- `tools/latest.py` 프로그램마다 최신 호 키·요약 유무 확인 / `tools/check.py` 기기 7가지 × 탭마다 화면 점검(올리기 전에)
- `CLAUDE.md` 이 저장소에서 가판대를 고치는 Claude가 따르는 작업 지침
- 같은 저장소의 `question/`·`stock/`·`ai-guide/`는 다른 작업이 만드는 앱입니다(가판대 파일과 섞지 않음)

## 어떻게 바로 반영되나

이 페이지는 열릴 때마다 각 프로그램의 목록 파일(`/news/data/index.json`, `/bios/issues/index.json` …)을 직접 읽습니다.
새 호가 올라가면 그 목록이 바뀌므로 가판대는 따로 고칠 필요가 없습니다. GitHub Pages 캐시 때문에 최대 10분쯤 늦을 수 있고, 켜 둔 화면은 20분마다 다시 읽습니다.

## 탭

- 맨 앞 **새로 나온 것**(아직 안 연 새 호만, 숫자 표시)과 맨 끝 **전체**는 저절로 생깁니다. 그 사이 분류 탭은 `projects.json`의 `tabs`(`id`·`name`·`note`)이고, 각 프로그램은 `tab` 값으로 그 탭에 들어갑니다(지금: 시장·투자 / 과학 / 질문 / 놀이). `tab`이 없거나 모르는 값이면 '그 밖의 것' 탭이 생깁니다.
- 안 본 새 호가 있는 탭에는 파란 점이 붙습니다. 위쪽 '안 본 것' 알약을 누르면 '새로 나온 것' 탭으로 갑니다.
- 처음 열면: 안 본 새 호가 있으면 '새로 나온 것', 없으면 지난번에 본 탭. 주소 끝에 `#market`처럼 탭 id를 붙이면 그 탭으로 바로 열립니다.
- 탭을 눌렀는데 카드가 화면 아래로 넘치면 탭 막대가 맨 위에 붙도록 올라가서, 한 탭의 카드가 한 화면에 들어옵니다.
- 탭 안에서는 자주 나오는 순서(매일 → 매주 → 분기 → 비정기 → 언제든)로 놓입니다.

## 화면 배치

PC·태블릿 가로는 표지를 크게 세운 카드, 태블릿 세로·휴대폰 가로는 표지 왼쪽·요약 오른쪽 카드 두 줄, 휴대폰 세로는 한 줄 목록으로 바뀝니다.

- 카드 요약은 양쪽 정렬입니다(글자 사이에서 줄을 바꿔 오른쪽 끝을 맞춤). 제목은 낱말을 쪼개지 않고 두 줄 길이를 고르게 맞춥니다(양쪽 정렬하면 낱말 사이가 크게 벌어져서).
- 칸 제목은 늘 한 줄입니다. 설명까지 다 안 들어가면 설명을 빼고 이름만 보여서, 옆 칸 카드와 높이가 어긋나지 않습니다.
- 모든 카드는 가장 큰 카드의 높이에 맞춥니다(글은 자르지 않음).
- 넓은 화면에서 한 탭의 카드가 한 줄에 다 안 들어가면 카드 너비를 조금 줄여(최소 200px) 한 줄에 담습니다. 그래도 안 되면 다음 줄로 넘깁니다('전체' 탭처럼 많은 경우). 카드 5장이 놓이도록 카드 판은 1320px(1440px 넘는 화면은 1480px)까지 넓어집니다.
- 그래도 카드가 창 아래로 넘치면(1366×768 노트북, 태블릿 세로의 5장 탭 등) 카드 안 여백과 줄 간격을 좁혀 한 화면에 담습니다(`.tight`, 열 때·창 크기가 바뀔 때마다 다시 잼). 표지 비율(3:4)과 글자 크기는 그대로라 표지 그림이 잘리지 않고, 좁혀도 안 들어가면 원래 크기로 둡니다. 휴대폰 세로 목록은 원래 내려 읽습니다.
- 휴대폰 홈 화면에 추가하면 앱처럼 열립니다(manifest.webmanifest, icons/).

## 요약 문장 (summaries.json)

카드의 요약은 각 호를 읽고 **전체를 관통하는 핵심 생각을 완결된 한 문장**으로 직접 쓴 것입니다(결론이나 질문으로 끝맺음, 말줄임표·"이런 내용이 있어요" 식 소개 금지).
`summaries.json`에 `프로그램 id → 호 키(날짜|호수, 풍향계는 미국장 날짜) → 문장`으로 적습니다. 새 호가 나오면 예약 작업이 읽고 써 넣습니다.
`python3 tools/latest.py`를 돌리면 프로그램마다 지금 최신 호의 키, 요약이 있는지, 무엇을 읽고 써야 하는지(`projects.json`의 `read`, `summaryTone`)가 나옵니다.
여기에 없으면 목록 JSON의 `summary` 필드를 쓰고, 그것도 없으면 요약 없이 제목만 보입니다(아무 문장이나 뽑아 넣지 않음).

## 읽음 표시

카드를 누르면 그 기기 브라우저에 "어느 호까지 눌러 봤는지"를 적어 둡니다(localStorage, 서버로 보내지 않음).
더 새로운 호가 나오면 파란 점과 주황색 "새로 나왔어요 / 아직 안 봤어요"가 다시 켜집니다.
휴대폰과 PC는 따로 기억하고, 가판대를 거치지 않고 각 사이트를 직접 열면 기록되지 않습니다.

## 새 프로그램 추가하기

`projects.json`의 `projects`에 한 덩어리를 더합니다. `tab`은 들어갈 분류 탭 id, `group`은 `daily`·`weekly`·`quarterly`·`irregular`·`always` 중 하나(새 칸이 필요하면 `groups`에 추가).

### 1) 목록 JSON이 이미 있는 경우 — `index`

```json
{
  "id": "새이름",
  "name": "보일 이름",
  "kind": "종류(예: 주간 매거진)",
  "desc": "한 줄 소개",
  "group": "weekly",
  "tab": "science",
  "url": "/새이름/",
  "schedule": { "days": [5], "time": "19:00" },
  "accent": "#3b82f6",
  "source": {
    "type": "index",
    "index": "/새이름/data/index.json",
    "list": "issues",
    "label": "제{no}호",
    "title": "{title}",
    "cover": "/새이름/img/{date}/cover.jpg"
  },
  "cover": { "style": "plain" }
}
```

- `schedule`: `{"days":[…],"time":"HH:MM"}`(0=일 … 6=토, 한국 시각) 또는 분기마다 `{"every":"quarter","lagDays":45}`(분기 말 + 45일 = 13F 공시 기한).
  - `schedule.days`: 0=일 … 6=토, `time`: 한국 시각.
  - `"usMarket": true`이면 전날(미국 날짜)이 주말이거나 `usMarketClosed`(미국 증시 휴장일)인 한국 아침은 발행이 없는 날로 칩니다(Seok's Paper·풍향계). 휴장일 목록은 해마다 news-data의 `config/us_market_holidays.json`과 맞춰 더합니다. 다음 호 안내와 "예정보다 늦어지고 있어요" 표시에 씁니다. 비정기면 빼고 `statusText`를 씁니다.
- `list`: 목록 배열이 있는 자리(배열이 파일 맨 위면 `""`). 각 항목에 `date`(YYYY-MM-DD)가 있어야 합니다.
- `label`·`title`·`cover`·`link`: `{필드}` 자리에 그 호의 값이 들어갑니다. `{no|pad2}`는 두 자리(01)로 채웁니다.
- `summary`: 카드에 넣을 핵심 한 문장. 후보를 여러 개 적으면 처음으로 값이 있는 것을 씁니다(예: `["{summary}", "{lead}"]`). `summaryAfter`는 그 글자 뒤만, `sentences`는 몇 문장을 쓸지(기본 1 = 첫 문장, -1 = 마지막 문장, 0 = 전부), `summaryHtml`은 호별 HTML에서 `selector`로 뽑습니다.
  **발행할 때 목록 JSON의 각 호에 `summary`(핵심 한 문장)를 같이 적어 두면 그 문장이 그대로 카드에 실립니다.**
  요약은 결론을 맺거나("…입니다.") 질문으로 끝나는("…일까?") 완결된 한 문장으로 씁니다. 화면에서 자르지 않으므로 말줄임표로 끝나지 않게 합니다.
- `publishAt`: 미리 올려 두고 정해진 시각에 공개하는 경우 그 필드 이름.
- `detail`: 표지 정보가 호별 파일 안에 있을 때 그 파일 주소. 그 안의 값은 `{d.필드}`로 씁니다.
- `cover.style`: `plain`(표지 그림 그대로) · `overlay`(그림 위에 `mast` 제호와 제목) · `paper`(종이 신문, SVG 그림. 제호가 길면 `mastSize`로 글자 크기를 줄인다 — 기본 25, 카드 너비의 %(cqw). 예: SEOKONOMY 14. 그림(`svg`·`cover`)이 없으면 큰 제목 아래 `source.deck`(부제)·`source.body`(두 단 본문)·`source.foot`(아래 줄)로 지면처럼 채운다 — SEOKONOMY는 `{reading}`·`{summary}`·`{range}`) · `type`(글자만) · `wind`(풍향계 전용) · `tower`(구구탑 전용: 탑 그림) · `guru`(구루 13F 전용: 많이 산·판 종목 막대) · `stock`(Seok's Stock 전용: S&P500 몇 배 곡선, `source.type`도 `stock`).
- 구구탑에 새 층이 열리면 `projects.json`의 구구탑 `cover.reached`와 `floors`, `source.summary`를 고칩니다.

### 2) 새로 만드는 프로그램 — `hub.json` 하나만 두기

저장소에 아래 파일을 두고 발행할 때마다 갱신하면, `"source": { "type": "hub", "feed": "/새이름/hub.json" }`로 연결됩니다.

```json
{ "date": "2026-11-20", "label": "제3호", "title": "이번 호 제목", "summary": "핵심 한 문장", "cover": "img/2026-11-20/cover.jpg", "publishedAt": "2026-11-20T19:00:00+09:00" }
```

`cover`·`link`는 hub.json 위치 기준 상대 주소도 됩니다.

### 3) 발행이 없는 것(게임·도구) — `static`

표지 그림을 `assets/`에 넣고 `"source": { "type": "static", "label": "…", "title": "…", "cover": "assets/그림.jpg" }`.

## 가판대로 돌아가는 단추 (home.js)

각 프로그램 화면 왼쪽 아래에 '가판대' 단추가 떠 있습니다. 각 사이트의 index.html 맨 끝에 다음 한 줄이 들어 있고, 모양·동작은 이 저장소의 `home.js` 하나만 고치면 모든 사이트에 함께 바뀝니다.

```html
<script src="https://hangseokemail-spec.github.io/home.js" defer></script>
```

- 아래로 읽어 내려가면 숨고, 조금이라도 올리면 다시 나옵니다. 누르면 가판대로 오고, 떠날 때 보던 탭이 그대로 열립니다.
- **꾹 눌러 끌면 원하는 자리로 옮길 수 있습니다.** 놓으면 가까운 왼쪽·오른쪽 가장자리에 붙고, 그 자리는 이 기기에 기억됩니다(그 사이트 자리 + 아직 옮긴 적 없는 다른 사이트에도 같은 자리). 처음 한 번은 '꾹 눌러 끌면…' 말풍선이 뜹니다. 기억은 브라우저의 `seoks-home-pos-v1`.
- 옮기기 전 처음 자리는 `data-pos`(bottom-left·bottom-right·top-left·top-right), 아래쪽 단추와 겹치면 `data-lift="60"`처럼 올립니다(Nova는 60).
- 새 프로그램을 만들 때도 index.html 끝에 이 한 줄을 넣습니다.

예전처럼 `https://hangseokemail-spec.github.io/?tab=wind`로 들어오면 증시현황판(`/seoks/`)으로 넘어갑니다.
